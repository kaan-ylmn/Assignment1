# BirdOfPrey - Assignment 1

This repository contains the C++ implementation of the core game classes for the BirdOfPrey project. The primary goal of this assignment was to transition Blueprint-based logic into a robust and performant C++ foundation.

## 🚀 Completed Tasks
- **C++ Class Implementation:** Converted 15 core Blueprint classes to C++, ensuring correct inheritance and naming conventions.
- **Project Structure:** Optimized the repository by excluding unnecessary temporary files (Saved, Intermediate, Binaries) via `.gitignore`.
- **Branch Management:** Developed features using a dedicated `feature/cpp-classes` branch and merged them into `main` following professional Git workflows.

## 🛠 Tech Stack
- **Engine:** Unreal Engine 5
- **Language:** C++
- **Version Control:** Git / GitHub
